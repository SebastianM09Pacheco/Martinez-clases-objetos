## Sobre el proyecto

Este proyecto lo realicé como parte de una actividad de programación en C#. La idea es trabajar con clases y objetos creando un pequeño registro de productos.

El programa permite ingresar tres productos y mostrar sus datos en pantalla.

## ¿Qué puede hacer el programa?

- Pedir el nombre, código, precio y cantidad de un producto.
- Comprobar que el nombre no esté vacío.
- Verificar que el precio sea mayor que cero.
- Evitar que se introduzcan cantidades negativas.
- Comprobar que los datos numéricos sean válidos.
- Calcular el valor total de cada producto según su precio y cantidad.

## Archivos

- **Program.cs:** aquí está el código principal, donde se solicitan los datos y se crean los productos.
- **Producto.cs:** aquí está la clase Producto, con sus propiedades, constructor y método para mostrar la información.

## ¿Cómo ejecutar el programa?

Se puede abrir el proyecto en Visual Studio y ejecutarlo presionando F5.
